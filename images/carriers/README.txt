통신사 로고 넣는 곳
====================
이 폴더에 아래 이름으로 로고 파일을 넣으면, 인터넷 요금 비교표 등의 통신사 배지(KT / SK / LG U+)가
자동으로 로고 이미지로 바뀝니다. 파일이 없는 통신사는 기존 글자 배지가 그대로 보입니다.

  kt.svg   (또는 kt.png / kt.webp)
  sk.svg   (또는 sk.png / sk.webp)
  lg.svg   (또는 lg.png / lg.webp)

- 권장: 가로형 로고, 배경 투명 SVG 또는 PNG (높이 약 56px 이상)
- 로고는 각 통신사의 공식 브랜드 자료(공식 파트너/대리점용 가이드)에서 받은 파일을 사용하세요.
- 같은 이름으로 여러 확장자가 있으면 svg → png → webp 순서로 사용합니다.
