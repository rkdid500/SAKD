통신사 로고 (서버 반영용)
==========================
사이트의 통신사 배지(요금 비교표, 상담 신청 창 등)에 쓰이는 로고입니다.

[사이트에서 사용하는 파일]  images/carriers/*.webp
  kt.webp  sk.webp  lg.webp                       ← 통신 3사
  skylife.webp  lg-hellovision.webp  skb-saving.webp   ← 알뜰 3사

  - 형식: WebP (투명 배경), 크기: 모두 1600 × 400px (4:1) — 고해상도(2~3배 화면)에서도 선명하게 표시
  - 모든 로고는 여백을 잘라 낸 뒤 같은 캔버스(4:1)에 가운데 맞춤으로 통일해 두었습니다.
  - 화면에는 CSS가 가로 152px(PC) / 72px(모바일) 박스로 줄여서 보여 줍니다.
  - 파일명은 코드(js/internet-new.js 의 LOGO_FILE)와 연결되어 있으니 바꾸지 마세요.

[원본]  images/carriers/original/*.png
  - 제공받은 로고 원본(PNG)입니다. 다시 가공하거나 다른 크기가 필요할 때 사용하세요.
  - 사이트 화면에서는 사용하지 않습니다.

[교체 방법]
  - 같은 이름의 WebP로 덮어쓰면 됩니다. (파일이 없으면 .png → .svg 순으로 찾고, 끝내 없으면 글자 배지로 표시)
  - 로고를 바꾼 뒤에는 js/internet-new.js 의 LOGO_V 값을 바꿔야 브라우저 캐시가 갱신됩니다.
  - 로고는 각 통신사의 공식 브랜드 자료(대리점·파트너용 가이드)에서 받은 파일을 사용하세요.
