통신사 로고
===========
인터넷 요금 비교표 등의 통신사 배지(KT / SK / LG U+)에 쓰이는 로고 파일입니다.

  kt.png / sk.png / lg.png        ← 화면에 사용 중 (파일명 고정, svg·png·webp 모두 가능)
  lg-hellovision.png, skb-saving.png, skylife.png   ← 아직 화면에 쓰지 않는 다른 사업자 로고

- 로고를 바꾸려면 같은 이름으로 덮어쓰면 됩니다. (svg가 있으면 svg → png → webp 순서로 사용)
- 로고 파일이 없는 통신사는 글자 배지로 표시됩니다.
- 원본(고해상도) 파일은 images/통신사 로고/ 에 있으며 저장소에는 올리지 않습니다.
