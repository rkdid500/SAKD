시안 (참고용) — 새 홈페이지 첫 디자인 시안
==========================================
이 폴더는 실제 사이트가 아니라, 구조를 잡을 때 만든 **참고용 시안**입니다.
(파란 헤더, 히어로 슬라이더, 휴대폰/인터넷 카드, 후기 구성을 한 페이지로 만든 것)

- index.html / style.css / script.js : 브라우저에서 index.html 을 열면 바로 보입니다. (인터넷 연결 필요: 글꼴 CDN)
- 정수기 관련 내용은 제외된 상태입니다.
- 실제 사이트(index.html, internet.html, phone.html)는 이 시안에서 **구조만** 가져오고,
  색은 싹딜 컬러(민트·네이비)로 바꾸고 문구는 새로 작성했습니다.
- 이 시안의 문구·구성에는 참고한 타사 사이트와 비슷한 부분이 있어서,
  **공개 배포(GitHub Pages)에서는 제외**되어 있습니다. (저장소 루트의 _config.yml 의 exclude)
  → 문구를 그대로 쓰지 말고 참고용으로만 보세요.
