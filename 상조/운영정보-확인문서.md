# 싹딜 상조 리디자인 — 운영정보 확인 문서 (내부용)

대상 화면: `상조/상조-리디자인.html` (고객에게 공개되지 않는 문서입니다. `_config.yml`의 `exclude`로 공개 사이트에서 제외됨)

고객 화면에서 **노란 점선 밑줄**로 표시된 문구는 운영 정책이 확정되면 바꿔야 하는 문구입니다. 상단 안내 줄에도 같은 설명이 있습니다.

## 0. 가격 (타사 참고가격, 2026.10.29 공개가격 조사 기준)

가격은 `상조-리디자인.html` 스크립트의 `PRICING` 객체 한 곳에서만 관리합니다. 화면에는 "장례 형태" 영역의 접이식 설명(구성과 참고가격 보기)에만 표시됩니다.

| 형태 | 비교 참고가격 | 기준 | 비고 |
|---|---|---|---|
| 무빈소 장례 | 1,190,000원 | 아정당 무빈소 기본상품 | 공식 공지: 2026.8.14부터 99만 원 → 119만 원 |
| 일반 장례 | 3,490,000원 | 교원라이프 다이렉트 349 | 15,000원 × 232회 + 10,000원 × 1회 = 3,490,000원. 조사한 4개 브랜드·13개 상품 중 최저가(시장 전체 최저가 아님). 해당 조사 상품 평균은 약 494.8만 원이나 화면에 "평균"으로 쓰지 않음 |

- 싹딜 실제 판매가격: **미확정(null)**. 확정되면 `own: { amount: 숫자(원) }`만 입력하면 메인 가격이 "싹딜 판매가격"으로 바뀌고 타사 참고가격은 별도 라벨로 남습니다.
- 절약액: 타사와 동등한 제공 조건이 확인되어 `comparable: true`로 바꾼 경우에만 계산·표시됩니다. 현재 숨김.
- 두 형태의 가격 차이를 절약액·할인율로 표시하지 않습니다.
- 화면의 두 형태("무빈소 장례", "일반 장례")는 **안내용 분류**이며 확정 판매상품이 아닙니다.

- 현재 폼은 전송 기능이 없습니다. 제출하면 "신청 접수 기능이 연결되지 않아 내용이 전송되지 않았다"고 안내합니다.
- 연결 지점: `상조-리디자인.html` 스크립트의 `// TODO: 실제 신청 API 연결` (전송 항목: name, phone, memo)
