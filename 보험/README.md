# 보험 (싹딜 보험 시안)

- `보험.html` — 최신 고객용 디자인 시안 (로고·입체 아이콘이 파일 안에 포함되어 단독으로 열림)
- `운영정보-확인문서.md` — 내부용 운영정보 확인 문서 (고객 화면에 표시하지 않음)
- `images/` — 원본 이미지 (`싹딜 로고.png`, `상담사-3D.webp`)
- `백업/` — 이전 작업 버전
  - `보험전작업.html` — 디자인 기준본 (재작업 직전 버전)
  - `단순화버전.html`, `신뢰개선전.html`, `글줄인버전.html`, `개편전.html`

시안이며 실제 상담은 접수되지 않습니다. 공개 배포 전 운영정보 확정이 필요합니다.
