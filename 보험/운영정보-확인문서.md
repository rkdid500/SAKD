# 싹딜 보험 — 운영정보 확인 문서

> **내부 검토용 문서입니다. 고객용 화면(`insurance.html`)에는 표시하지 않습니다.**
> `insurance.html`은 디자인 시안이며, 아래 "시안에서 사용한 가정"은 **확인된 운영 사실이 아닙니다.**
> 모든 항목이 "확정"으로 바뀌기 전에는 공개 서비스로 배포하지 마세요.

작성 기준 파일: `보험상조/insurance.html` (디자인 시안)
상태 표기: **미확정** = 아직 아무것도 확인되지 않음 / **확인 필요** = 담당자 확인 후 확정 / **확정** = 증빙 자료 있음

## 1. 항목별 정리

### 1) 실제 상담 운영사와 싹딜의 역할

| 구분 | 내용 |
|---|---|
| 시안에서 사용한 가정 | 싹딜이 고객 접점(페이지·신청 접수)을 맡고, 상담은 보험 상담이 가능한 별도 주체가 진행한다고 가정. 화면에는 운영사 이름·로고·등록 정보를 넣지 않았다. |
| 실제 확인할 내용 | 실제 상담을 진행하는 법인(또는 제휴 대리점)의 상호, 싹딜과의 계약 관계(위탁·제휴·직영), 고객 문의 시 책임 주체, 화면에 표시할 상호·대표자·연락처 |
| 확정 여부 | **미확정** |

### 2) 자격·등록 정보 및 확인 자료

| 구분 | 내용 |

## 2. 시안에 사용한 가상 비교 예시 (참고)

숫자는 디자인 설명용이며, 계산은 다음과 같이 맞춰 두었다.

| 항목 | 점검 전(만원/월) | 점검 후(만원/월) | 변화 이유 |
|---|---:|---:|---|
| 암 진단비 2,000만원 | 3.6 | 3.6 | 유지 |
| 입원일당 특약 2건 | 2.4 | 1.2 | 지급 조건이 같을 때만 한 건 정리 (다르면 유지) |
| 소액 특약 여러 개 | 4.1 | 2.0 | 겹치거나 쓰임이 적은 특약부터 확인 |
| 뇌혈관·심장 진단비 | 1.9 (1,000만원) | 3.3 (2,000만원) | 부족할 수 있어 증액 검토, 보험료 상승 |
| **합계** | **12.0** | **10.1** | 월 −1.9 (= −1.2 −2.1 +1.4) |

- 진단비 금액이 달라진 구성이므로 화면에서 "같은 보장"이라고 표현하지 않는다.
- 이 수치는 실제 상품·견적·실적이 아니므로 대표 성과로 사용하지 않는다.

## 3. 공개 전 필요한 검토 사항

1. 위 1)~8) 항목을 증빙 자료와 함께 **확정**으로 바꾼 뒤, 고객용 문구를 실제 정책에 맞게 수정한다.
2. 첫 화면 상단의 안내(`디자인 시안 · … 실제 상담은 접수되지 않습니다.`)와 신청서의 "실제 상담은 접수되지 않습니다" 문구는 **실제 접수 기능과 정책이 갖춰질 때까지 유지**한다.
3. "무료", "0원", "가입 의무 없음", "가입 후 지원" 표현은 해당 정책이 확정되기 전에는 게시하지 않는다.
4. 광고·표시 관련 법령 및 보험 모집 관련 규정에 따른 사전 검토(광고 심의, 필수 안내 문구, 비교·안내 표현의 적정성)를 받는다.
5. 개인정보 수집·이용 동의 화면, 제3자 제공 동의, 개인정보처리방침, 마케팅 수신 동의를 법무와 함께 확정한다.
6. 신청서를 실제 접수와 연결하려면 전송·저장 방식, 보관·파기, 접근 권한, 장애 시 안내를 별도로 설계한다. (현재 시안은 어떤 정보도 전송·저장하지 않는다.)
7. 푸터에 상호·대표자·사업자등록번호·연락처 등 필수 사업자 정보를 실제 값으로 채운다.
8. 보험사명·로고·등록증·후기는 계약·허락·검증이 끝난 자료만 사용한다.
9. 공개 배포는 위 항목이 모두 확정된 뒤에 한다. (시안 파일은 `noindex`로 설정되어 있으나, 이는 배포 승인을 대체하지 않는다.)
